Detailed Description

Topology of a conforming 3D mesh (used by CMesh3D), stored as flat arrays indexed by entity id.

The input topology is: points, face_vs (vertices of each face, in order around it), cell_fs and cell_fs_flag (faces of each cell and whether each one is oriented inward), cell_hex, cell_input_vs and cell_kernel (and cell_vs for the HEX type). MeshProcessing3D::build_connectivity derives everything else:

  • edges sorted by (min, max) vertex id, edge_vs = (min, max);
  • face_es[f][j] = edge (face_vs[f][j], face_vs[f][j + 1]);
  • cell_vs: hexes in navigation order (a face, then the opposite vertices), other cells sorted; cell_es sorted;
  • every incidence list (vertex_*, edge_fs/hs, face_hs) sorted by id, vertex_vs[v][k] being the other vertex of the edge vertex_es[v][k];
  • the boundary flags. Face ids are the creation order and are never renumbered.
