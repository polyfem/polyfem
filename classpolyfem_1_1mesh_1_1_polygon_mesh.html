Detailed Description

Minimal polygonal surface mesh used as the storage of CMesh2D.

Vertices carry 3D positions (z = 0 for planar meshes), facets are polygons stored as contiguous ranges of corners, and each corner knows the facet across the edge that starts at it. Edges and boundary flags are derived data filled by Navigation::prepare_mesh().

The connectivity semantics (facet gluing, facet flipping and deletion) and the point arithmetic follow geogram's GEO::Mesh, which this class replaces, so that meshes built with it are identical to the ones PolyFEM used to build.
